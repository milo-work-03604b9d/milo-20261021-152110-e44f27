Inventory Management SVG Module

Overview:
A modular SVG component designed for indie games with a 'Retro-Industrial' aesthetic. It features an amber/green high-contrast palette, scanline textures, and a grid-based layout.

Technical Specs:
- Format: SVG (Scalable Vector Graphics)
- Styling: Embedded CSS for scanlines and glow effects.
- Features: Durability bars, status indicators, and a utilitarian grid.

Usage:
Can be embedded directly into web pages or imported into game engines (Unity, Godot) as a UI element. The scanline effect is achieved via a repeating linear gradient.

Target Audience:
Indie game developers looking for ready-to-use UI assets for sci-fi or industrial-themed games.
